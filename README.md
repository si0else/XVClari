# Vértice Motors — Plantilla demo

Plantilla estática para una automotriz local.

## Cómo usar

1. Abrí la carpeta en Visual Studio Code.
2. Reemplazá las imágenes de `/img`.
3. Editá los datos de vehículos en `js/script.js`.
4. Cambiá nombre, teléfono, dirección, Instagram y textos en `index.html`.
5. Abrí `index.html` con Live Server o directamente en el navegador.

## Imágenes

La plantilla necesita estos archivos:

- `img/hero.jpg`
- `img/used.jpg`
- `img/auto-1.jpg`
- `img/auto-2.jpg`
- `img/auto-3.jpg`

Podés reemplazarlos manteniendo esos nombres.

## WhatsApp

Buscá `5491100000000` en los archivos y reemplazalo por el número real, incluyendo código de país y sin `+`, espacios ni guiones.

## Personalización

El catálogo se controla desde `js/script.js`, dentro del array `vehicles`.
Cada vehículo tiene:

- marca
- modelo
- año
- tipo
- kilometraje
- combustible
- transmisión
- precio
- imagen
- estado
- descripción
- galería
